# Release playbook

Rules for shipping new versions of the Demo mobile app.

## Cadence
Planned release - every 4-6 weeks. Hotfixes - as needed, outside the schedule.

## Process
1. All milestone issues are Done or Canceled
2. Regression testing passed on the staging environment
3. Release builds assembled for iOS and Android
4. Release approved by the project lead

Details in the child documents: the pre-release checklist and the rollback procedure.
