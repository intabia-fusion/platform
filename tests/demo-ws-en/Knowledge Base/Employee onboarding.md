# Employee onboarding

Checklist for a new Demo employee's first two weeks.

## Day one
- [x] Issue a work laptop and access (email, tracker, chat)
- [x] Add to the "development" or "marketing" channel based on role
- [x] Introduce to the lead and the team

## First week
- [ ] Attend an intro meeting with the project lead
- [ ] Read the "Release playbook" document
- [ ] Get a first small task in the tracker

## Second week
- [ ] Close the first task independently
- [ ] Join the next "Planning" meeting

For any questions - the "development" channel, the whole team is there.
