# Release rollback

What to do if a critical bug is found in a release after publishing.

1. Log the problem as an Urgent-priority issue
2. Assess whether it can be closed with a hotfix in a few hours
3. If not - roll the store listing back to the previous version
4. Notify the team in the "development" channel
5. After the fix - the usual release process per the checklist
