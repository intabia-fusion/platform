# Глоссарий

Термины, которые часто встречаются в задачах и обсуждениях команды «Демо».

- **Релиз** - версия приложения, выпущенная в магазины приложений.
- **Этап (Milestone)** - группа задач, привязанная к конкретному релизу.
- **Регрессия** - ранее исправленная ошибка, которая проявилась снова после изменений.
- **Хотфикс** - срочное исправление, выпускаемое вне обычного графика релизов.
- **Каталог** - список товаров, доступных для заказа в приложении.
- **Онбординг** - первое знакомство пользователя (или сотрудника) с продуктом.
