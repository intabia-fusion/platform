# Онбординг сотрудника

Чек-лист первых двух недель нового сотрудника компании «Демо».

## Первый день
- [x] Выдать рабочий ноутбук и доступы (почта, трекер, чат)
- [x] Добавить в канал "разработка" или "маркетинг" по профилю
- [x] Познакомить с руководителем и командой

## Первая неделя
- [ ] Пройти вводную встречу с руководителем проекта
- [ ] Изучить документ "Регламент релизов"
- [ ] Получить первую небольшую задачу в трекере

## Вторая неделя
- [ ] Самостоятельно закрыть первую задачу
- [ ] Поучаствовать в ближайшей "Планёрке"

По любым вопросам - в канал "разработка", на связи вся команда.
