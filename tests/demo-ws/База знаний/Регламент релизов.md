# Регламент релизов

Правила выпуска новых версий мобильного приложения «Демо».

## Периодичность
Плановый релиз - раз в 4-6 недель. Хотфиксы - по необходимости, вне графика.

## Процесс
1. Все задачи этапа переведены в статус Done или Canceled
2. Пройдена регрессия на тестовом стенде
3. Собраны релизные сборки для iOS и Android
4. Релиз согласован руководителем проекта

Подробности в дочерних документах: чек-лист перед релизом и порядок откатa.
