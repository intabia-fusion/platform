HyperDX UI (not published outside the cluster yet):

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ .Values.clickstack.fullnameOverride | default "monitoring" }}-app 3000:3000
  open http://localhost:3000

The first visit asks to create an account; it stays inside this cluster. OTLP ingestion starts
only after that first registration: HyperDX enables the collector's OTLP receiver once a team
exists. For the same reason a fresh install shows no data until the account is created.

Platform services send OTLP to:

  http://{{ .Values.clickstack.fullnameOverride | default "monitoring" }}-otel-collector.{{ .Release.Namespace }}.svc.cluster.local:4318

Set it in the stand's values as:

  otel:
    OTEL_EXPORTER_OTLP_ENDPOINT: http://{{ .Values.clickstack.fullnameOverride | default "monitoring" }}-otel-collector.{{ .Release.Namespace }}.svc.cluster.local:4318

Ingestion check:

  kubectl -n {{ .Release.Namespace }} logs deploy/{{ .Values.clickstack.fullnameOverride | default "monitoring" }}-otel-collector --tail=50
