# gh-picker

TUI инструмент для cherry-pick коммитов из upstream/develop в текущую ветку.

## Установка

```bash
cd dev/gh-picker
go build -o gh-picker .
```

Или добавьте в PATH:
```bash
ln -s $(pwd)/dev/gh-picker/gh-picker /usr/local/bin/gh-picker
```

## Использование

Запустите из корня git-репозитория:

```bash
./dev/gh-picker/gh-picker
```

## Интерфейс

Инструмент имеет двухпанельный интерфейс:

- **Левая панель** - список коммитов из upstream/develop, которых нет в текущей ветке
- **Правая панель** - дифф выбранного коммита

## Управление

| Клавиша | Действие |
|---------|----------|
| `↑/k` | Вверх по списку |
| `↓/j` | Вниз по списку |
| `PgUp/K` | Прокрутка диффа вверх |
| `PgDn/J` | Прокрутка диффа вниз |
| `Space/Enter` | Выбрать/снять выбор коммита |
| `a` | Выбрать все/снять все |
| `c` | Выполнить cherry-pick выбранных коммитов |
| `r` | Обновить список коммитов |
| `?` | Показать/скрыть помощь |
| `q/esc` | Выход |

## Индикаторы

- `[ ]` - коммит не выбран
- `[x]` - коммит выбран
- **Зеленый ✓** - коммит уже cherry-picked
- **Фиолетовый фон** - текущий выбранный коммит

## Примечания

- Cherry-pick выполняется в порядке от старых коммитов к новым
- При конфликте инструмент сообщит об ошибке
- Для отмены cherry-pick используйте `git cherry-pick --abort`
