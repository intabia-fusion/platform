# ui-kit и глобальные селекторы потомков

- Глобальные правила темы вида `.container span { ... }` бьют по внутренним `span` кнопки кита (`button__icon`,
  `button__label`): их специфичность выше scoped-стилей кита. Пример: `.hulyTableAttr-header span` (`tables.scss`)
  давал иконке `margin-left` и `flex-grow`, и она съезжала внутри квадратной кнопки.
- Чинить глобальное правило (`& > span`, только свой контент контейнера), а не кнопку кита.
