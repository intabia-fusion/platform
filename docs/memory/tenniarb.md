# Tenniarb

- Значения параметров попадают в JS как строки, кроме чисел: `"false"` truthy. Условия boolean-параметров писать как `flag === "true"` (`../tenniarb/go/exec/scene_eval.go:13-20`).
- Выражение на вложенном `use` видит параметры этого компонента, а не родителя. Для видимости такой части использовать `styles` родителя с литералами `hidden yes/no`.
- Keyframes ищутся в том же компоненте, где написан `animation name ...`. Блок на уровне файла не виден вложенному `item`.
- `style`-блок части добавляет свойства перед ее собственными. Литерал части надо убрать, если style должен его переопределить.
- MCP `render` вычисляет параметры в `element`, но не в корневом каталоге библиотечных `item`. Для визуальной проверки параметров использовать `element`-каталог или экземпляр на экране.
- `tenn-render` запускать от корневого `PlatformDesign.tenn` с dotted path экрана. Передача части с `entry` не дает контекст mounted-библиотек.
