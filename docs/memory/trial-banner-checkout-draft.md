# Плашка "Пробный период" и черновики чекаута

Область: [Биллинг](../features/billing.md)

- `checkWorkspaceLimits` выбирал для плашки самый новый tier по `createdOn` в любом статусе. Черновик чекаута новее живого триала -> `onTrial=false` и пропавший чип free уже во время оплаты. Плашку ведёт granting-tier (`grantsPlan`), фолбэк - самый новый тир, который не черновик (`isCheckoutDraft`). - `plugins/billing-resources/src/utils.ts`.
- Чип free/overdue гасит СТАТУС выбранного тира (`overdueOnFree`: `ReadOnly`, `Expired`, истёкший `Trialing`), а не отсутствие `freeLimits`: account подставляет `freeLimits` каждому Tier на чтении (`fillFreeLimits`), включая черновик. Поэтому `latestTier(...)?.freeLimits` в pod-billing/pods-server от черновика не страдает - только плашка. - `plugins/billing-resources/src/stores/subscription.ts`, `server/account/src/operations.ts`.
- `providerData.draft:true` ставится при создании черновика, остаётся при закрытии неоплаченным (`ABANDONED`/`REJECTED`) и снимается только `CONFIRMED`. `pending:true` = открытый черновик, `draft:true` = признак после закрытия; читаются вместе через `isCheckoutDraft`. - `services/payment/pod-tbank-subscriptions/src/server.ts`, `foundations/core/packages/account-client/src/utils.ts`.
- `PastDue` + `pending:false` для `grantsPlan`/`isFailedRenewal` неотличим от провала продления: план выдаётся. У черновика нет `rebillId`, поэтому `needsRenewal` его не берёт, `retryAttempt` остаётся 0, grace (`retryAttempt >= 3`) не наступает - тир висит `PastDue` и выдаёт план бессрочно, без писем и без `ReadOnly`. - `services/payment/pod-tbank-subscriptions/src/{server,scheduler,storage}.ts`.
- У отменённой платной подписки `buildCanceledSubscriptionData` оставляет `rebillId`, поэтому оживление в `PastDue` даёт списание от scheduler'а через `retryAfter` (1 ч) - деньги уходят, если карта ещё жива в TBank (`removeSubscriptionCard` best-effort), и после `PLAN_CHANGE` в воркспейсе два plan-granting тира. - `services/payment/pod-tbank-subscriptions/src/server.ts`.
- Терминальный вебхук (`REJECTED`/`REVERSED`/`REFUNDED`) переводит в `PastDue` только `Active` или `PastDue` (`isFailedRenewal`); `Canceled`/`ReadOnly` терминальны. `alreadyApplied` нужен только для повтора того же статуса на `PastDue` (иначе сбрасывается `retryAfter`). - `services/payment/pod-tbank-subscriptions/src/server.ts`.
- Granting-черновик блокирует `trialExpiry` через `hasGrantingTier`: триал не истекает в free, напоминание о конце триала не уходит. - `services/payment/pod-payment/src/trialExpiry.ts`.
- Прод проверен: `provider='tbank' AND status IN ('past_due','readonly') AND COALESCE(provider_data->>'pending','false') <> 'true' AND provider_data->>'rebillId' IS NULL AND provider_data->>'cardId' IS NULL` - 0 строк. Ремонт и миграция не нужны. - `<ns>.subscription`.
